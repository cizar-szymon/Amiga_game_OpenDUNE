OPENDUNE (Amiga) - release history
==================================

Reporting bugs: give the release number (main menu, bottom left, or in the
Shell: Version OpenDUNE), say what happened and add the report files from
OpenDUNE/saves - F10 writes bugNNN.txt, bugNNN.dat and bugNNN-*.bmp.
Reports: github.com/cizar-szymon/Amiga_game_OpenDUNE (Issues).


0.50 (31.10.2026)
-----------------

- Languages: German (Westwood's original texts from your own Dune II) and
  Polish, chosen in Options -> Game controls -> Language. The words on the
  buttons and on the top bar in the chosen language.
- LAN game: the messages at the end of a game and the network's errors in
  the chosen language; a player who left is shown so on every Amiga
  (lan_info=1); the top bar and the LAN line without leftovers of old text.
- LAN game: the server saves with the SAVE button on the top bar beside
  OPTIONS (the others have none); a rare OUT OF STEP after closing the save
  or Options window fixed; the lobby shows just the map's name and the
  level's number.
- Pause (P): a large white PAUSE in the middle of the map.
- LAN game: when a player's Amiga hangs, resets or loses the network
  (no answer for 10 s), the game pauses for everyone with "No contact
  with ...". The server can then save it (SAVE) - that player stays in
  the save, so when they are back all load it in the lobby and play
  on - or play on without them (P). Before, the game waited forever,
  and with two players the server won at once. A player who loses the
  server gets "The connection to the server is lost."
- Small maps (missions 1 and 2) in the middle of the view at the larger
  resolutions.
- Step by step installation in Polish, English and German
  in one file, Install.txt.
- The game's drawer has a plain drawer icon, MakeMusic a loudspeaker with
  notes.
- Missing data files: the game shows a window with the missing .PAK
  files and the directory it looks in (in English, Polish and German)
  instead of quitting without a word. MakeMusic without SOUND.PAK says
  the same in three languages, and Return closes its window.
- MakeMusic shows its progress: a dot per 20 s of music recorded, so it
  is plain that it works and has not hung (a piece takes about a minute).
- The MUSIC directory made by MakeMusic can be deleted. Before, it was
  protected from deletion; for an old one: Protect MUSIC +d.
- The Amiga is checked at the start (a window in English, Polish and
  German): without an RTG graphics card with Picasso96 (an 8-bit mode of
  640x480 or more) or with less than 8 MB of free Fast RAM the game says
  what is missing and does not start (it uses about 6.5 MB). On a
  68020/68030 it warns that it may run slowly (Play / Quit); on a 68000
  it says that a 68020 is needed.
- Options - Amiga info: without a Warp (WarpTool) the window shows the
  CPU clock as the game measures it (e.g. "~50 MHz"); on a 68060 to 1 MHz.
- Settings in the icon too: each option of opendune.ini can be a Tool Type
  of the OpenDUNE icon (e.g. SCREENMODE=800x600) or a Shell argument, and
  wins over opendune.ini. The icon has the usual ones in brackets as
  hints. MakeMusic takes DATADIR and MUSIC_DIR from the game's icon too.
- The letter P in a save's name no longer pauses the game.
- Started from the icon: no console window opens when the game ends.
- The F10 report gives the program's real build date.
- Checked: a LAN game of three players for 67 minutes (all sums the
  same), the heaviest missions 7-9, saves loaded in another language,
  players and the server dropping out.


0.49 (30.10.2026)
-----------------

- MakeMusic: an Amiga program that records the game's music itself from
  the player's own data (SOUND.PAK) into the MUSIC directory - no PC
  needed. Double-click the MakeMusic icon, about 35 minutes on a 68060 at
  100 MHz. It also records a piece the PC recordings lacked (music no. 5).


0.48 (29.10.2026)
-----------------

- Smooth map scrolling pixel by pixel (cursor keys, screen edge): the view
  glides instead of jumping 16 pixels. The map view is one tile smaller
  (black strips beside the panel and below). The old scrolling by whole
  tiles: smooth_scroll=0 in opendune.ini.
- Quicker upload of the picture to the card while scrolling (Warp 1260,
  100 MHz: 43-55 frames a second, 30-40% of the CPU free while scrolling
  all the time).


0.46 (29.10.2026) - the first release
-------------------------------------

- Dune II (OpenDUNE, the engine of the PC version 1.07) on a 68040/68060
  Amiga with an RTG card: screen 400x300 to 960x540 (Options ->
  Resolution), the menus enlarged in the middle.
- Map scrolling by the card's blitter, at the screen edges and with the
  cursor keys; smooth unit movement between the game's steps (up to 60
  frames a second).
- Group selection with a rubber band, orders with the right button, the
  group in the panel (SQUAD) with action buttons for all of it.
- Map zoom x2 / x3 (Z, mouse wheel).
- Pause (P), a smooth build percentage, LOAD / SAVE on the top bar, "Main
  menu" in Options.
- LAN game for up to 3 players: servers found on the network, houses,
  levels 2-9 (36 maps), fog of war for each player, chat (Tab), pause,
  save and load.
- Music: recordings of the AdLib music played from disk (made once with a
  tool from your own game data, directory MUSIC), Music ON/OFF in Game
  controls.
- Options -> Amiga info (CPU, memory, card, the Warp card's clock), Show
  FPS in Game controls, screen corner -> Workbench.
- F10 on every screen: a bug report with the game state, a saved game and
  the picture.
